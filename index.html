Die Beurer-CSV enthält Grundumsatz und Leistungsumsatz möglicherweise nicht. Diese zwei Werte lassen sich aus einem Screenshot auslesen und anschließend der Messung zuordnen. Die OCR-Bibliothek wird bei Bedarf aus dem Internet geladen; das Bild selbst wird im Browser verarbeitet und nicht an einen Server dieser App gesendet.

AtlasSometria · Private lokale Web-App · Messwerte sind Schätzungen des Messgeräts, keine Diagnose. Daten werden nur in deinem Browser gespeichert (sofern der Browser lokalen Speicher für diese Datei erlaubt). Bei Browserdaten-Löschung können sie verloren gehen – exportiere regelmäßig eine ergänzte CSV.
